Need full, unmasked owner details?
This is a police matter, not a lookup

If you genuinely need full owner name and address — for example, after a real hit-and-run or property damage — the correct path is:

  • File a police complaint / FIR, citing the vehicle number and what happened
  • Police and courts have authorized access to full, unmasked VAHAN records specifically for this purpose
  • This also creates an official record, which matters far more than owner details alone if you want the matter actually resolved

Any third-party site or app offering full owner name + address "instantly" for a fee is operating outside what the government intends to be public — worth being cautious of those, not just skeptical.

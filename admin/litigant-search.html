Litigant Search (Private)
Private tool
Search cases by person name
Looks up Indian court cases where the name appears as a petitioner or respondent, using the official eCourtsIndia API. Open any result for full case details.
Read before relying on results. Court records name people, not identities: many people share a name, so a match is only a lead. Confirm with father/husband name, address, age or case particulars before treating a case as belonging to your subject. Use only for lawful, legitimate purposes (due diligence, your own matters, clients). Each search uses paid API credits. Nothing you search is stored by this site.
Tip: start with the default. If you get too many unrelated people, use Exact phrase with the full name. If you get nothing, try Fuzzy (Indian names have many spellings).

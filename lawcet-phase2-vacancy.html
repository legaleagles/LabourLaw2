TG LAWCET 2026 · LLB 3-YDC ONLY

Phase 2 Seat Vacancy Estimator

Cross-references each college's official sanctioned intake against real Phase 1 allotment data, so you can see which colleges likely have the most seats actually open for Phase 2.

📋 How This Is Calculated

Estimated Vacancy = College Intake (total sanctioned seats) − Phase 1 Allotted Candidates.

Source data: the official 2026-27 LLB 3-Year Degree Course college/intake list, and the official TG LAWCET Phase 1 allotment results. Both are real published figures — this page only does the subtraction, it does not estimate or predict anything on its own.
⚠️ This is an estimate, not an official seat matrix. Actual Phase 2 vacancies depend on how many Phase 1 allottees actually joined (vs. were just allotted), any seat surrenders, upgrades, or cancellations between phases — figures the counseling authority alone can confirm. Always verify final vacancy on the official TG LAWCET website before making any decision. Two colleges show "No Data" because no matching Phase 1 record was found for them in the allotment file — this does not necessarily mean zero seats were filled there.
